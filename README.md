SHOPPING LIST

The Shopping List application is a mobile application developed using Flutter and Dart. The purpose of this application is to help users manage items they want to buy. Users can add items, view their shopping list, mark items as bought, and delete items they no longer need.

 Main Features

1 Add Items

Users can enter the name of a shopping item and add it to the list using the Add button or the Enter key.

2 Prevent Empty Items

The application checks whether the user has entered an item. If the input is empty, the application displays a message asking the user to enter an item.

3 Prevent Duplicate Items

The application checks whether an item already exists in the list. It prevents the same item from being added again, ignoring differences between uppercase and lowercase letters.

4 Delete Items

Users can remove individual items by clicking the delete icon beside the item.

5 Mark Items as Bought

Users can select a checkbox to mark an item as bought. The item is displayed with a line through its text.

6 Count Remaining Items

The application displays the number of shopping items that have not yet been marked as bought.

7 Clear Bought Items

Users can remove all items marked as bought by selecting the Clear Bought Items button.
